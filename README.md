# GKI Presenter Desktop

Unduhan resmi aplikasi desktop GKI Presenter. Source code aplikasi tetap berada di repository private; repository ini hanya berisi installer publik dan checksum.

## Unduh

Buka [Releases](https://github.com/alvinmingguw/gki-presenter-downloads/releases) dan pilih versi terbaru.

- **macOS**: DMG universal untuk Apple Silicon dan Intel. Buka DMG, lalu seret app ke Applications.
- **Windows**: installer Setup untuk Windows x64.
- **Verifikasi**: cocokkan SHA-256 installer dengan `SHA256SUMS.txt` pada release yang sama.

Installer hanya diunggah setelah build CI selesai.
